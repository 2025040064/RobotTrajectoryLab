# RobotTrajectoryLab v1.0.1

基于 MATLAB 的中文机器人轨迹规划与仿真工作台，提供可安装的 Windows x64 图形程序与完整 MATLAB 源码。

## 本版功能

- UR5 六关节同步五次轨迹、正运动学与雅可比分析，支持速度/加速度解析峰值检查、固定路径时间缩放及采样碰撞检查。
- 移动机器人四邻域 A*、矩形障碍编辑、足迹与安全距离膨胀、逐线段安全复检、直连简化和不安全圆角回退。
- 六页中文界面、三维场景、播放/暂停/进度与倍速、原始和处理后指标对比。
- MAT 保存与恢复、CSV 数值导出、PNG 图表与实验记录。

## Windows 安装与卸载

下载附件 `RobotTrajectoryLab_Setup.exe`，按向导安装。安装器约 3.4 MB，采用联网获取 MATLAB Runtime 的方式，不包含完整运行库。

需要 **Windows x64 + MATLAB Runtime R2025a**；不需要 MATLAB 开发环境。已安装对应运行库可直接复用。首次初始化可能需要一分钟左右，期间显示加载进度。默认数据目录为用户主目录下的 `RobotTrajectoryLab_Data/`。

本版修复旧版启动时显示黑色终端的问题，增加图形启动器与运行库自动定位。附件 `RobotTrajectoryLab_Uninstall.exe` 为 12 KB 的卸载入口，可分别打开软件和运行库官方卸载向导；运行库是共享组件，卸载后依赖它的程序将无法运行。卸载入口本身不会删除实验数据。

附件同时提供 `RobotTrajectoryLab_UserGuide.pdf`（使用说明）和 `RobotTrajectoryLab_TechnicalNotes.pdf`（技术要点与创新点），下载后放在同一文件夹即可，无需另行解压。GitHub 自动生成的 Source code 文件用于获取源码。本地交付文件夹中的两份 PDF 保留中文文件名，内容与线上附件一致。

- 新电脑的完整安装流程未另行验收；卸载入口仅验证界面、安装发现与官方卸载器路径，未执行实际卸载。
- 机械臂碰撞检查是指定角度分辨率下的采样检查；时间缩放不消除碰撞。移动场景展示平面几何路径，不包含差速动力学或真实机器人控制。
- 本阶段不含 IK、RRT/PRM、通用求解器优化或批量统计。官方工具箱算法与项目实现的安全检查、后处理和交互流程分别说明，详见技术文档。
