RobotTrajectoryLab 1.0.0

Windows x64. Requires MATLAB Runtime R2025a.
Install Runtime using the supplied RobotTrajectoryLab_Setup.exe (Internet required).
The package does not include an offline Runtime installer.

Extract this folder to a writable location. Start Start_RobotTrajectoryLab.cmd.
The script stores projects, experiments, and logs in its Data folder.
Starting the EXE directly uses USERPROFILE/RobotTrajectoryLab_Data instead.
Wait for Runtime initialization on the first launch.

This application provides UR5 joint quintic trajectories, analytic time scaling,
four-neighbor A-star grid paths, safety checks, 3D playback, and MAT/CSV/PNG exports.
It is a software simulation and does not control physical robots.

See the supplied Chinese homework PDF for workflows, results, and limitations.
