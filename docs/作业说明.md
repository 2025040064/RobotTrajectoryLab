# RobotTrajectoryLab 机器人运动规划作业说明

作者：Astrspire　版本：1.0.0　日期：2026 年 10 月 25 日

## 一 软件用途与功能

本作业使用 MATLAB 实现中文机器人运动规划软件，将参数设置、轨迹计算、三维回放、结果分析与数据保存放在同一界面中。软件包含 UR5 六自由度机械臂和圆形移动机器人两条操作流程，适合观察关节运动、比较时间缩放效果，以及研究栅格地图上的安全路径。

六个页面分别承担实际功能：工作台新建、打开和保存项目；模型与环境页查看 UR5、设置关节约束和编辑地图障碍；运动规划页编辑起终状态与参数并执行计算；三维仿真页播放、暂停、重置和拖动进度；优化与分析页比较轨迹与指标；实验记录页恢复输入快照、查看结果并导出数据。

本程序仅进行软件仿真，不连接真实机器人。机械臂采用运动学模型，移动机器人展示平面路径，没有实现逆运动学、差速动力学、轨迹跟踪或批量实验。

## 二 运行方法

### Windows 运行包

使用 Windows x64。首次运行先打开 `installer/RobotTrajectoryLab_Setup.exe`，安装器联网获取 MATLAB Runtime R2025a。Runtime 是运行库，不是 MATLAB 开发环境。运行包不包含离线 Runtime，因此换到未安装 Runtime 的电脑时需要联网安装。

已安装对应 Runtime 时，解压 `RobotTrajectoryLab_V1.0_Windows.zip` 到可写目录，双击 `Start_RobotTrajectoryLab.cmd`。脚本将实验、日志和项目写入同目录的 `Data` 文件夹。直接运行 EXE 时，默认写入用户主目录下的 `RobotTrajectoryLab_Data`。首次启动需要初始化运行库，请等待窗口出现。

### MATLAB 源码

解压 `RobotTrajectoryLab_V1.0_Source.zip`，将 MATLAB 当前目录切换到工程根目录，输入 `app = main;`。开发环境为 MATLAB R2025a，需要 Robotics System Toolbox 和 Navigation Toolbox。重编译另需 MATLAB Compiler；普通使用不需要其他优化求解器或第三方库。

## 三 UR5 机械臂操作与算法

1. 研究对象选择“六轴机械臂 · UR5”，在模型页查看机械臂，也可以添加箱形障碍。
2. 在运动规划页输入六个关节的起点、终点、运动时间、采样周期及速度、加速度上限。界面位置使用度，内部统一转换为弧度。
3. 执行规划，检查诊断信息。成功后进入三维仿真，使用播放、暂停、进度条和倍速查看运动。
4. 在优化与分析页执行解析时间缩放，比较原始与当前的运动时间、关节曲线和 TCP 路径，然后导出或保存实验。

模型采用官方 `universalUR5`，末端坐标系为 `tool0`。正运动学使用 `getTransform`，雅可比使用 `geometricJacobian`，轨迹使用 `quinticpolytraj`。设归一化时间 τ=t/T、关节位移 Δq=q1−q0，零端速度和零端加速度轨迹为：

`q(t) = q0 + Δq (10τ³ − 15τ⁴ + 6τ⁵)`

每个关节的解析峰值为 `vmax = 15|Δq|/(8T)`、`amax = 10√3|Δq|/(3T²)`。程序用解析峰值判断约束，避免只检查离散采样点。时间缩放在固定关节路径上选择满足各关节速度、加速度上限的同步时长，并保留原始结果。

碰撞检测采用官方 `checkCollision`，包含自碰撞和环境箱体，仅跳过父子连杆配对。默认相邻检查配置最大关节变化不超过 0.02 rad。这是采样检查，不是连续安全证明；时间缩放也不会消除碰撞。默认速度 1 rad/s、加速度 2 rad/s² 是可编辑的仿真设定，不是厂家额定值。

## 四 移动机器人操作与算法

1. 研究对象选择“移动机器人 · 栅格”，设置地图行列、格宽、原点、机器人半径和安全距离。默认地图为 60×80 格，每格 0.1 m。
2. 通过表格或地图添加、移动、删除矩形障碍，并点击设置起终单元格。第一行位于地图顶部，世界坐标 Y 向上，起终点使用格子中心。
3. 执行规划，在地图和诊断区查看原始、简化及最终路径，再进入三维仿真查看地面机器人运动。
4. 在分析页比较路径长度、转角和保守净空，保存 MAT 项目或导出结果。

地图采用 `binaryOccupancyMap`，路径搜索采用 `plannerAStarGrid`。固定四邻域，代价与启发式均为 Manhattan，关闭启发式扰动。规划前按机器人半径、安全距离和半格对角线进行保守膨胀，并单独处理地图边界。

程序对原始路径、直连简化路径、Chaikin 圆角候选逐段复检：计算完整线段到原占用格中心的最短距离，同时计入占用格外接圆，避免漏掉线段中间穿障和擦角。圆角默认两轮；如果候选不安全，保留已经通过检查的简化折线，并报告原因。

三维画面是平面路径的空间展示。回放参考时间为路径长度除以参考速度，不包含差速动力学和加减速过程；保守膨胀可能拒绝狭窄通道。

## 六 保存与复现

项目 MAT 保存配置，单次结果 MAT 保存输入快照、原始与处理后轨迹、约束、诊断和版本信息。CSV 列名包含单位，PNG 保存分析图。参数修改后，旧结果标为失效，需重新规划后播放和导出。运动时间、规划耗时、后处理耗时、参考回放时间分别记录。

源码入口是 `main.m`，独立入口是 `RobotTrajectoryLab.m`，业务代码在 `+rtl` 下。`examples/run_examples.m` 可复现默认实验，`run_tests` 运行完整测试，`validate_ui` 生成可见窗口操作截图。测试清单见 `results/validation/test_results.csv`，EXE 部署证据见 `results/deployment`，构建说明与限制见 `docs/ACCEPTANCE.md`。

本次作业交付到此结束，后续算法、通用约束优化与真实机器人控制不属于已实现功能。
